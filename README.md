# OnePavan — Portfolio PWA

Personal portfolio of **Pavan Kumar Banala**, Senior Integration Architect & Java Technology Leader.

The site lives in [`portfolio-pwa/`](./portfolio-pwa). It's a dependency-free, installable PWA
written in plain HTML, CSS and JavaScript, with no build step.

```bash
cd portfolio-pwa
python -m http.server 5173   # → http://localhost:5173
```

See [`portfolio-pwa/README.md`](./portfolio-pwa/README.md) for the placeholders to fill in,
architecture notes and deploy options. Netlify deploys it via the root `netlify.toml`.
